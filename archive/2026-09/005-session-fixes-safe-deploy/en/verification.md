## Deviations agreed during implementation

- Malformed JSON bodies answer `400 Malformed JSON body` instead of 500 (`errors.ts`, task 3).
- `trust proxy` verified with an `X-Forwarded-For` request instead of a temporary `req.ip` log.
- `dist.prev/` and `dist.next/` added to `backend/.gitignore` (task 8 fix).
- pm2 calls in `deploy.ps1` go through `cmd /c` (task 8 fix).
