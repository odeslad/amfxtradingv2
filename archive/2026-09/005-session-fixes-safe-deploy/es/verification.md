## Desviaciones acordadas durante la implementación

- Los cuerpos JSON malformados responden `400 Malformed JSON body` en vez de 500 (`errors.ts`, tarea 3).
- `trust proxy` verificado con una petición `X-Forwarded-For` en lugar de un log temporal de `req.ip`.
- `dist.prev/` y `dist.next/` añadidos a `backend/.gitignore` (fix de la tarea 8).
- Las llamadas a pm2 en `deploy.ps1` van vía `cmd /c` (fix de la tarea 8).

## Pendiente del usuario

Nada. El one-liner antiguo `pm2 start … --node-args …` ya no existe en ningún script; si alguna vez se arranca el backend a mano, usar `pm2 start C:\amfxtradingv2\backend\ecosystem.config.js`.
